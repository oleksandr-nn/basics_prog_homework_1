# Factorial

Скрипт на Python, який рахує факторіал числа `num` (`num! = 1 × 2 × ... × num`, `0! = 1`).

## Запуск

```bash
python factorial.py
```

```
Enter a number: 5
120
```

## Як це працює

```python
def factorial(num):
    result = 1
    for i in range(2, num + 1):
        result *= i
    return result
```

Змінна `result` починається з `1`, бо множення на одиницю не змінює добуток. Цикл множить `result` на кожне число від 2 до `num` включно (верхня межа в `range` не входить, тому `num + 1`). Для `5` виходить `1 → 2 → 6 → 24 → 120`.

Для `0` і `1` діапазон порожній, цикл не виконується, і повертається `1`, що відповідає означенню.
